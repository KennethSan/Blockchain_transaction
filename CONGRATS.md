## 🎮 HOW IT WORKS

1. **Create Transactions**
   - Go to Transactions page
   - Fill in sender, receiver, amount
   - Submit (saved as "pending")

2. **Mine Block**
   - Go to Dashboard
   - Click "Mine Block"
   - System performs proof-of-work
   - Transactions become "mined"
   - Block added to chain

3. **Validate Chain**
   - Click "Validate Chain"
   - System checks all blocks
   - Verifies hash integrity
   - Returns valid/invalid status

4. **View Blockchain**
   - Go to Blocks page
   - See all mined blocks
   - View transactions in each
   - See hash connections
